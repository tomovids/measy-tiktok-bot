Privacy Policy

Measy Slideshow · Last updated 8 October 2026

Measy Slideshow is an internal tool run by Measy, the meal-planning app. It sends Measy's own daily recipe slideshow to Measy's own TikTok account as a draft. This page explains what information the tool handles. It covers this tool and this website only; the Measy app has its own privacy policy.

What we get from TikTok

When the Measy TikTok account connects the tool, TikTok gives us:

  • an access token and a refresh token, which let the tool send drafts to that account;
  • the account's TikTok ID (open ID) and the permissions it granted: basic profile information (user.info.basic) and uploading drafts (video.upload).

We don't collect or store anything about any other TikTok user, and we don't read the account's followers, messages, comments or videos.

How we use it

Only to upload Measy's own recipe slideshows to the Measy account's TikTok drafts and to check that each upload arrived. Nothing is posted publicly by the tool; a person posts each draft in the TikTok app.

Where it's kept

The tokens are encrypted before they are stored, and the key that unlocks them is kept separately as an encrypted GitHub secret. The tool runs on GitHub Actions and this website is hosted on GitHub Pages. The day's slideshow images are published on this website so that TikTok can download them; they are replaced with the next day's images.

Who else is involved

  • TikTok receives the slideshow and caption for the draft.
  • GitHub runs the tool and hosts this website.
  • OpenAI generates the cover picture and the caption text from the recipe names. No personal information is sent to OpenAI.

We don't sell or share the information with anyone else, and we don't use it for advertising.

How long we keep it

The tokens are kept while the account stays connected and are deleted when the connection is ended. The account owner can end it at any time in the TikTok app (Settings and privacy → Security → Manage app permissions).

Visitors to this website

This website has no cookies, sign-ups or analytics. GitHub, which hosts it, may log technical information such as IP addresses; see GitHub's privacy statement.

Children

The tool and this website are not aimed at children and don't knowingly collect children's information.

Changes

If this policy changes we'll update this page and the date at the top.
